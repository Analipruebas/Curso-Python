# Curso de Python

Repositorio donde documento mi avance en un curso de Python, con los ejercicios y proyectos de cada tema.

Soy **QA Engineer Senior** con 9 años de experiencia en pruebas funcionales, de integración y de API en banca. Estoy aprendiendo Python para llevar mi experiencia hacia la **automatización de pruebas** (Pytest, Requests y Selenium).

> Este repositorio contiene el trabajo de un curso de aprendizaje. No son proyectos de empleadores anteriores.

## Contenido

| Carpeta | Tema | Proyecto final |
|---|---|---|
| `Tema_0` | Introducción y preparación del entorno (Python y VS Code) | - |
| `Tema_1` | Sintaxis, variables, strings, números y funciones | Generador de GamerTags |
| `Tema_2` | Operadores (aritméticos, asignación, booleanos, comparación, identidad, pertenencia y lógicos) | Calculadora de fitness y salud personal |
| `Tema_3` | Tipos de datos complejos (listas, tuplas, diccionarios, sets, bytes y NoneType) | Analizador de rentabilidad inmobiliaria |
| `Tema_4` | Estructuras de control de flujo (`if/elif/else`, `for`, `while`, `break`, `continue`, `pass`) | Sistema de pedidos de restaurante con delivery |
| `Tema 5` | Programación orientada a objetos (namespace, scope, clases, métodos, atributos, decorators y herencia) | Sistema de gestión de citas médicas |

## Qué practiqué

- Funciones, argumentos, `return` y docstrings.
- Estructuras de datos: listas, tuplas, diccionarios y sets.
- Condicionales y ciclos.
- Programación orientada a objetos: clases, herencia y decorators.
- Lectura de archivos de texto (`libros.txt`).

## Por qué esto importa para QA

Estas bases me sirven para escribir validaciones, manejar datos de prueba y estructurar frameworks de automatización, por ejemplo con el patrón Page Object Model.
